# 🧠 Research Identity

I am a PhD researcher at ENSA Fes working on **hybrid AI–robotic systems for personalized assistance and monitoring in healthcare environments**.

My work focuses on integrating:
- Robotics and control systems  
- Machine learning and deep learning  
- Cognitive and psychological modeling  
- Multimodal perception (vision, gaze, behavior, physiological signals)  
- Human-centered intelligent systems for healthcare

# 🚀 Selected Projects

---

## 🤖 Adaptive Human–Robot Interaction System
**Stack:** ROS 2 • OpenCV • Python • Behavior Modeling  

- Real-time robotic system adapting to human behavior signals  
- Integrates attention tracking and interaction context  
- Designed for assistive healthcare environments  

---

## 👁️ Gaze & Attention Analysis Pipeline
**Stack:** Python • Eye-tracking • Statistical Modeling • Signal Processing  

- Extraction of gaze patterns (fixations, saccades, dwell time)  
- Cognitive load estimation from behavioral signals  
- Used in experimental neuroscience and AI research  

---

## 🧠 Multimodal Behavioral Dataset Framework
**Stack:** Python • Pandas • NumPy • ML preprocessing  

- Unified dataset combining:
  - digital interaction logs  
  - behavioral data  
  - physiological signals  
- Designed for longitudinal AI modeling  

---

## 🏥 AI-Based Healthcare Monitoring Prototype
**Stack:** Computer Vision • ML • Raspberry Pi • IoT  

- Real-time monitoring system for behavioral and environmental signals  
- Detects anomalies using multimodal inputs  
- Target: assistive healthcare environments  

---

## 📊 Statistical Modeling for Behavioral Analysis
**Stack:** Python • Statsmodels • Scikit-learn  

- Regression and predictive modeling of behavioral patterns  
- Feature engineering for psychological and digital usage metrics  
- Supports cognitive and attention research
